# NoblesDAO API

See the repository [README](../README.md#run-the-api-and-client-locally) for
Firebase setup and local run instructions.

The implemented endpoints are `POST /create_account` and `POST /login`.
Import `postman/NoblesDAO.postman_collection.json` into Postman to try them.
The collection uses placeholder account details; use a test account in your own
Firebase project.
