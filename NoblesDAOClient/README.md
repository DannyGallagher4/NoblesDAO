# NoblesDAO Client

This is the React frontend for NoblesDAO. For complete Firebase configuration
and local run instructions, see the repository
[README](../README.md#run-the-api-and-client-locally).

Available scripts:

- `npm start` starts the development server at <http://localhost:3000>.
- `npm test` runs the Create React App test runner.
- `npm run build` creates a production build in `build/`.
